## Key Features

Abdullah Al Kulaib Documentation offers powerful features to streamline your documentation process. From project creation to version control, our platform ensures your docs are always up-to-date and accessible.

<Steps>
  <Step title="Create Your First Project" icon="plus">
    Start by creating a new project to organize your documentation.
    ````bash
    # Create a new documentation project
    abdullah-kulaib create-project --name "My Project" --description "Project documentation"
    ````
  </Step>
  <Step title="Add Team Members" icon="user-plus">
    Invite your team members to collaborate on the documentation.
    ````bash
    # Add a team member to the project
    abdullah-kulaib add-member --project-id 123 --email "team@example.com" --role editor
    ````
  </Step>
  <Step title="Import Existing Docs" icon="upload">
    Import your existing documentation files to get started quickly.
    ````bash
    # Import documents from a directory
    abdullah-kulaib import-docs --project-id 123 --source "/path/to/docs" --format markdown
    ````
  </Step>
</Steps>

## API Overview

Our RESTful API allows you to programmatically manage your documentation projects and integrate with other tools.

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  // Get project details
  const response = await fetch('/api/projects/123');
  const project = await response.json();
  console.log(project.name);
  ```
  ```python
  # Get project details
  import requests
  response = requests.get('/api/projects/123')
  project = response.json()
  print(project['name'])
  ```
</CodeGroup>
